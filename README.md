# PackForge v3.28 — Campaign Counter + 250-Card Sets

- Campaign REP/ranks replaced by a simple 3-digit completion counter.
- Every completed campaign adds exactly 1.
- Campaign reward bonus rises 1% per completion, capped at +100% at 100.
- Milestone rewards at 25 / 50 / 75 / 100 and every 25 after 100.
- Active campaign route/progress bars glide continuously using native CSS transitions rather than per-frame JavaScript loops.
- Every permanent set now contains exactly 250 cards.
- Per set: 15 Ultra, 10 Secret, 7 Ghost, 5 God, 3 Ascendant.
- Higher rarity names are curated to feel more powerful; Pokémon Ascendants are Mew, Mewtwo, and Arceus.
- Existing card IDs are retained and 125 new IDs per set are appended.
- Existing local save key remains unchanged.
